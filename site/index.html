A practical workflow

From brief to film, with a human in the loop.

01 · WRITE

Give your agent a brief

Describe the audience, message, brand, and formats. The film contract keeps each scene editable.

02 · REVIEW

Inspect and refine

Use the editor for wording, timing, sound, and variants. Validation catches common implementation mistakes.

03 · RENDER

Export the versions

Render one film or a matrix of hooks, themes, sizes, and saved versions to MP4.

Quick start

Try it locally.

git clone https://github.com/abdelrahmanrageh/seekframe
cd seekframe
npm install && npx playwright install chromium
npm run editor

The npm packages are not published yet; for now, clone the repo. The editor includes a brand panel for colours, logos, fonts, a new-film wizard, and setup checks. The CLI and MCP server expose the same core operations to agents and CI.
