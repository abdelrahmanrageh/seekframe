# 03 · Brief → script

**Result:** a scene table with timings, on-screen text, picture, and a sound column. This becomes the manifest's `scenes` and cues.

```
Using docs/<project>-brief.md and brand/brand.json, write a script for a <N>-second <aspect> film in <languages>.
Output a table: # · name · time (s and frames at 30 fps, contiguous) · picture · on-screen text · sound (hits on cuts, silences).
Rules: one idea per scene (1–8 s, self-contained, clean first/last frames); a slow build and a short burst; real silence before the reveal;
three alternative HOOKS for the first 5–7 s; text short enough to read; no invented statistics.
List every wording/look choice that should become an editable param.
```
