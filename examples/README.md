# Examples (gallery)

Each example is a complete film you can open in the editor (`npm run editor`), plus the **prompt that produced it, the brief, and what the model got wrong**:
that last file is the most useful part when you write your own prompts.

| Example | What it shows |
|---|---|
| [`seekframe-launch`](seekframe-launch/) | 32 s launch film for Seekframe itself. 3 hooks × 4 looks (night, cream, electric, sunset), agent ticker, MCP prompt, cards flying into a checked grid, editor, variants wall, a halftone logo that builds itself dot by dot, and a generated 120 BPM score (intro, drop, breakdown, reveal). |
| [`akked-tick`](akked-tick/) (+ [`akked-tick-ar`](akked-tick-ar/)) | 35 s horizontal brand film. 3 hooks × 3 styles × 2 card shapes, English and Arabic (RTL) from one code base, brand kit, logo drawn from strokes, kinetic type, product UI in 3D, a **generated** deep sound design that follows each variant. |

More examples are planned (vertical app promo, logo sting, data story). Contributions welcome: see [CONTRIBUTING](../CONTRIBUTING.md).
