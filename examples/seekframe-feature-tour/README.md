# Seekframe Motion Study

A 24-second kinetic identity film and Seekframe editor demo. It pairs oversized type, bright geometric accents, drifting glossy forms, palette studies, and a frame-by-frame cue score.

Open `seekframe editor` and choose **seekframe-feature-tour**. Try the hero word and scale, colour world, flash colour, local logo upload, shape language, feature beats, and final line. The Variants tab includes three visual presets; Audio previews the generated score; Export renders an MP4.

All motion is deterministic and all assets are local. The supplied reference clips informed the broad visual direction; they are not used or included in the film.
