# Sound pack (optional)

Set the film's **Sound** param to *Sound pack* and it plays these files instead of the generated sounds.
Put your own (or licensed) effects here with these names; any you leave out are skipped with a warning.

| File | Used for |
|---|---|
| `whoosh.mp3` | zoom cuts |
| `swoosh.mp3` | streak cuts |
| `whoosh-fast.mp3` | flash and light-leak cuts (a long sweep, trimmed to 1.3 s) |
| `sharp-pop.mp3` | the hit on a flash cut, the hook's first word |
| `soft-pop.mp3` | one per word as headlines blur in (quiet) |
| `shine.mp3` | logo reveals, light leaks |
| `tap.mp3` | chapter pills, the URL |
| `pop.mp3` | cards, chips, partner logos |
| `success.mp3` | a number landing |

These files are not part of the repository (see `.gitignore`): sound packs usually forbid redistribution.
