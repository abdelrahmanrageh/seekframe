# create-seekframe

> Not published to npm yet. Until then use a clone of the repo (see the main README).

```bash
npm create seekframe@latest my-films
cd my-films && npx seekframe editor
```
Creates a folder with `films/`, `brand/`, agent instructions (`AGENTS.md`, Claude/Cursor/Copilot files) and `seekframe` installed. See https://github.com/abdelrahmanrageh/seekframe
